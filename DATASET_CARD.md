# Dataset card — Milestone-Oracle Diagnostic Suite

## Scope and conditioning (read this first)

**1. This is an anchored stress set, not a sample of math ability.**
Families enter the suite only if an anchor model *fails the parent directly* and *solves the
milestones individually*. Absolute category proportions are therefore properties of
(anchor x corpus x student), not estimates of any model's global ability.

How much does that matter? The *same* anchor and the *same* rule select **7% of MATH500 but
63-70% of AIME 2024/2025**. A tenfold swing in yield from an identical screen is the clearest
statement of what conditioning does. Use the suite for **contrasts between conditions on a fixed
set of problems**; do not read category shares as population estimates.

**2. Roadmaps are teacher-generated, and the readout carries teacher dependence.**
Milestone roadmaps are compiled by a frontier teacher (GPT-5.4 Thinking) from the problem statement
and its human reference solution. The teacher never sees any evaluated model's output, so the
decomposition is model-independent by construction — but it is not unique.

Measured dependence, same student and decoding, independent second teacher (n=53 families):

| Quantity | Agreement |
|---|---|
| C2 recovery, per family | 44/53 (83%) |
| C3 recovery, per family | 46/53 (87%) |
| Joint C2/C3 state | 41/53 (77%) |
| Under a controlled 4.1x granularity change, same teacher | 85% / 85% / 76% |

There is also a **level shift**: alternative roadmaps recover somewhat fewer families in absolute
terms (C2 20/53 vs 23/53; C3 19/53 vs 24/53). Contrasts are stable; absolute recovery levels are
teacher-sensitive. Report contrasts, not levels, when comparing across teachers.

**3. Category resolution has an operating envelope.**
The taxonomy's composition tier can only resolve when the milestone test is passable for the student
in question. On corpora where the teacher emits finer roadmaps on harder problems (4.7-6.1
milestones/family vs 2.2 on the main set), passing *every* milestone becomes rare and the residual
lands in MISSING-MILESTONE instead. Check the milestone-test pass rate before interpreting
composition-tier counts.

**4. Grading is deterministic and deliberately conservative.**
A strict symbolic cascade (boxed extraction -> schema-aware parse -> SymPy -> math-verify; abstain on
failure) with no LLM fallback. Audited over-acceptance <=0.25%. The cost is under-acceptance:
verifier/format artifacts account for **22-29% of each model's unrecovered residual**. Canonical
answers inherited from the source corpus can be brittle or wrong; three confirmed defects are fixed
in this release and the repair log is included.

## Intended use / out of scope

**Intended.** Comparing conditions on a fixed problem set; localizing where a model's failures sit;
tracking how a training intervention moves families between states; re-anchoring on your own model
with the released screen.

**Out of scope.** Leaderboard scoring; estimating a model's population math ability; reading category
shares as domain-general constants; using the composition tier without first checking the
milestone-test pass rate for your student.
